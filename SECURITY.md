# Security Policy

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you discover a potential security risk or data leak, report it privately through
GitHub Private Vulnerability Reporting in this repository's **Security** tab. If that
feature is unavailable, contact the repository owner through the organization profile
without including exploit details in a public issue.

Please include enough detail to reproduce the issue, and do not disclose vulnerability details publicly until we have investigated and provided guidance.

We aim to respond to all security concerns within **48 hours**.
